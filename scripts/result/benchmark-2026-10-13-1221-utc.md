last row (see Comparison), and the stat-dominated paths are flat.

## Same-machine Linux note (dual-boot)

The author runs two OSes on the exact same physical machine (dual-boot
GRUB), so this is not a "different hardware" comparison. The Linux side
shows the same pattern: reruns there land at 15–18s on the same `zod-main`
project, up from the ~13s v7 baseline (`benchmark-zod-v7.md`), including
runs on newer commits past this machine's HEAD. Both OSes slowing down in
lockstep on identical hardware points away from an OS-specific or
toolchain-specific cause and toward machine-side drift (disk state,
firmware/thermal behavior, or shared-SSD health) — or an as-yet-unknown
common factor. No regression claim follows in either direction until a
controlled quiet-box A/B is done.

## How to reproduce

```powershell
# Requires: Go 1.27+, MSYS2 UCRT64 gcc on PATH, CGO_ENABLED=1, sqlite3.exe
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
$env:CGO_ENABLED = '1'
go build -o ./srcinsight.exe ./cmd/srcinsight
powershell -ExecutionPolicy Bypass -File scripts/benchmark.ps1 -Root ./projectTest/zod-main -Runs 3 -NoCopy
# modify 1 file, then:
.\srcinsight.exe sync --root .\projectTest\zod-main   # no-op
```

Verify DB contents:

```powershell
sqlite3 .\projectTest\zod-main\.srcinsight\srcinsight.db `
  "SELECT COUNT(*) AS entries FROM entries; SELECT COUNT(*) AS links FROM links;"
sqlite3 .\projectTest\zod-main\.srcinsight\srcinsight.db `
  "SELECT kind, COUNT(*) FROM links GROUP BY kind ORDER BY COUNT(*) DESC;"
sqlite3 .\projectTest\zod-main\.srcinsight\srcinsight.db `
  "SELECT COUNT(*) AS cond_links FROM links WHERE cond != '';"
```

(Remove `projectTest\zod-main\.srcinsight` afterwards to leave the fixture
pristine — the script does this itself at the end in `-NoCopy` mode.)

## Notes

- The slowdown is selective: fresh-index parse/commit, incremental, and
  search inflate while stat-dominated skip/sync paths stay flat. A code
  regression in the pipeline would not spare exactly the stat paths while
  leaving output rows identical.
- The 3.84s fresh-run spread (with a cold 21.26s first run) against the
  0.05s spread on 2026-10-04 is itself the signal: this box is noisier
  than it was, despite a fresh boot with no editor/agent open.
